The dataset includes de-identified EEG and behavioural data from 123 participants, comprising resting-state EEG, working-memory EEG, TMS-EEG recordings from multiple stimulation sites, behavioural data from a multi-task cognitive battery, and associated event files, channel files, electrode/coordinate information where available, and scan listings. Structural MRI data were collected as part of the broader study but are not included in this public OpenNeuro release.

This dataset includes the following BIDS task labels and recordings:

•	rest: resting-state EEG recording
•	workingmemory: working-memory EEG and behavioural task data
•	tmseeg: TMS-EEG recordings
•	bar: bar task
•	bds: backwards digit span task
•	clt: colour task
•	gng: go/no-go task
•	nback: n-back task
•	opn: operation span task
•	ort: orientation task
•	sbs: symbol search task
•	sst: stop-signal task
•	sym: symmetry span task
